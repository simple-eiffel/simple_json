SIMPLE_JSON_STREAM - Memory-Efficient Streaming for Large Files

The elements of one JSON array come out one at a time; the document is never held whole. A file is read in chunks (64 KB by default, set_chunk_size to change), each element's text is cut out by a structural scanner that honours strings, escapes and nesting, and only that element is parsed. Memory is one chunk plus one element, whatever the file's size.

The array may be the document's root (make_from_file, make_from_string) or sit under a top-level key of a root object (make_from_file_at (path, "events"), make_from_string_at); the members before it are skipped by structure, not parsed. Iterate with across stream as ic loop ic.value ... ic.index ... end; a second across starts over. An element the parser refuses ends the stream with the reason in last_errors.

Measured with all assertions on: 3000 small objects stream in 375 ms from a file and 469 ms from a string (BIG_DOCUMENT_TESTS).

This component is part of the SIMPLE_JSON library providing comprehensive JSON manipulation capabilities. See the main User Guide for complete usage examples.
